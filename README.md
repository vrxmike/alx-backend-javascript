# ALX Backend JavaScript

A comprehensive learning repository containing backend JavaScript projects and exercises as part of the **ALX Software Engineering Program**. This collection covers modern JavaScript (ES6+), TypeScript, Node.js, and testing best practices.

## 📚 Repository Overview

This repository is a structured curriculum for mastering backend JavaScript development, progressing from fundamental ES6 concepts through advanced TypeScript and Node.js applications.

## 🗂️ Project Structure

The repository is organized into progressive modules:

- **[0x00-ES6_basic](0x00-ES6_basic)**: Introduction to ES6 fundamentals (arrow functions, template literals, destructuring).
- **[0x01-ES6_promise](0x01-ES6_promise)**: Mastering asynchronous JavaScript with Promises and async/await.
- **[0x02-ES6_classes](0x02-ES6_classes)**: Object-oriented programming using ES6 class syntax.
- **[0x03-ES6_data_manipulation](0x03-ES6_data_manipulation)**: Advanced data structures and array manipulation methods.
- **[0x04-TypeScript](0x04-TypeScript)**: Type-safe development with TypeScript interfaces, generics, and modules.
- **[0x05-Node_JS_basic](0x05-Node_JS_basic)**: Fundamentals of Node.js, HTTP servers, and Express.js.
- **[0x06-unittests_in_js](0x06-unittests_in_js)**: Testing practices using Mocha, Jest, and Chai.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher recommended)
- npm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vrxmike/alx-backend-javascript.git
   cd alx-backend-javascript
   ```

2. **Install dependencies (if applicable):**
   ```bash
   npm install
   ```

### Running Exercises
Each module typically contains:
- **Source files** - Main implementation code
- **Task files** - Specific exercises to complete
- **Tests** - Verification and validation of solutions

To run specific exercises:
```bash
npm run dev path/to/exercise.js
```

To run tests (if configured):
```bash
npm test
```

## 📖 Learning Path
We recommend completing the modules in order for optimal learning progression:

1. **Start with 0x00** - Build solid ES6 fundamentals
2. **Move to 0x01** - Understand asynchronous patterns
3. **Continue through 0x02-0x03** - Master OOP and data manipulation
4. **Dive into 0x04** - Learn TypeScript for type safety
5. **Explore 0x05** - Develop real backend applications
6. **Finish with 0x06** - Ensure code quality through testing

## 📝 Best Practices
When working through these exercises:

✅ **DO:**
- Read and understand each exercise completely before coding
- Write clean, readable code with meaningful variable names
- Add comments for complex logic
- Test your code thoroughly
- Review the solutions and learn from different approaches

❌ **DON'T:**
- Skip fundamental concepts to move ahead quickly
- Copy and paste solutions without understanding
- Ignore error messages and edge cases
- Neglect code documentation
